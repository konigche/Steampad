# Bundled emote pack — attribution

The emote animation files in this folder were obtained from the community collection
**KosmX/Emotecraft-emotes** (https://github.com/KosmX/Emotecraft-emotes), a repository published
under the **Creative Commons Zero v1.0 Universal (CC0-1.0)** license — public domain dedication,
no attribution required.

We credit the collection and its community authors anyway, in good faith. Per-file `author` fields
are preserved inside each JSON and shown in SteamPad's emote library UI.

Curation note: this is a hand-picked subset of that collection (12 mainstream emotes). The
repository's NSFW folder was deliberately excluded.

These files are DATA (animation keyframes), not code, and are unrelated to any mod's source code
or license. SteamPad's emote engine is an independent clean-room implementation — see
DECISIONS.md D080.
